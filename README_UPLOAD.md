# Wissenszeit PWA – Upload auf GitHub Pages

Dieses Verzeichnis ist der Inhalt, der in das Root-Verzeichnis des GitHub-Repositories `wissenszeit` hochgeladen wird.

Wichtig: Nicht den Ordner `Wissenszeit_PWA_v0_1` als Unterordner hochladen, sondern **seinen Inhalt**. Danach müssen im Repository direkt `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, `icons/` und `assets/` sichtbar sein.

Die vorhandene README.md im Repository kann bleiben. `index.html` wird von GitHub Pages bevorzugt.

Nach dem Commit kann die Aktualisierung von GitHub Pages einige Minuten dauern. Anschließend die Seite neu laden.

Auf dem iPhone in Safari: Teilen -> Zum Home-Bildschirm -> Als Web-App öffnen.
